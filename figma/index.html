    Apunts del tema

    Perfecte 🙂. Et deixe un tutorial bàsic, clar i usable de Figma orientat a dissenyar un lloc web, pensat perquè el pugues usar en classe o per autoaprenentatge i després portar-ho fàcilment a HTML/CSS o Tailwind.

    🟢 Tutorial bàsic de Figma per dissenyar un lloc web

    1️⃣ Crear un nou projecte

    1. Entra a https://figma.com
    2. Inicia sessió (Google funciona molt bé)
    3. Clica New design file
    4. Canvia el nom del fitxer (ex: Landing Page - Projecte 1)

    2️⃣ Crear el frame (lienç del web)

    En Figma, un Frame és com el <body> del teu HTML.

    1. Selecciona l’eina Frame (F)
    2. A la dreta, en Device presets → Desktop

    3. Tria:

    4. Desktop 1440

    5. o Desktop 1280

    👉 Aquest serà l’ample del teu web

    💡 Bona pràctica:

    • 1440 px (disseny modern)
    • Contingut centrat a 1200 px

    3️⃣ Estructura bàsica del web

    Crearem:

    • Header
    • Hero
    • Secció de contingut
    • Footer

    🔹 Header

    1. Rectangle (R)
    2. Amplada: 100%
    3. Alçada: 80 px
    4. Color de fons (ex: blau o gris fosc)

    Afegix:

    • Text → Logo
    • Text → Enllaços (Inici, Serveis, Contacte)

    🔹 Hero section

    1. Rectangle baix del header
    2. Alçada: 400–500 px
    3. Text gran (H1)
    4. Text descriptiu
    5. Botó (rectangle + text)

    🔹 Secció de contingut (cards)

    1. Crea un rectangle blanc

    2. Dins:

    3. Imatge (rectangle gris)

    4. Títol
    5. Text
    6. Botó

    👉 Duplica la card (Ctrl+D) per fer 3 columnes

    🔹 Footer

    1. Rectangle al final
    2. Alçada: 100 px
    3. Text petit (copyright, links)

    4️⃣ Auto Layout (CLAU)

    Auto Layout és l’equivalent mental de:

    • Flexbox
    • Grid

    Afegir Auto Layout

    1. Selecciona diversos elements
    2. Clica Shift + A

    3. A la dreta:

    4. Direction: Horizontal o Vertical

    5. Spacing: 16–24 px
    6. Padding: 16–32 px

    👉 Ideal per:

    • Menús
    • Cards
    • Botons
    • Formularis

    💡 Si aprens Auto Layout, Figma et sembla màgia

    5️⃣ Tipografia bàsica

    Recomanació simple:

    • H1 → 40–48 px
    • H2 → 28–32 px
    • Text → 16–18 px
    • Botons → 14–16 px

    Fonts recomanades:

    • Inter
    • Roboto
    • Open Sans

    6️⃣ Colors i estils reutilitzables

    1. Selecciona un color
    2. A la dreta → Style → Create style
    3. Nom: Primary / Secondary / Text

    👉 Igual que variables CSS

    7️⃣ Components (reutilització)

    Exemple: Botó

    1. Selecciona rectangle + text
    2. Ctrl + Alt + K (Create component)
    3. Duplica’l

    Avantatges:

    • Canvies un → canvien tots
    • Ideal per botons, cards, headers

    8️⃣ Prototip (clicable)

    1. Ves a la pestanya Prototype
    2. Arrossega el punt blau d’un botó
    3. Connecta a un altre frame
    4. Action: Navigate to
    5. Animation: Smart animate

    👉 Ja tens un web navegable

    9️⃣ Mode Developer (per portar-ho a codi)

    1. Selecciona un element

    2. A la dreta veuràs:

    3. Colors

    4. Fonts
    5. Marges
    6. CSS orientatiu

    👉 Ideal per:

    • HTML/CSS
    • Tailwind
    • Bootstrap

    10️⃣ Flux recomanat Figma → Web

    1. Figma: estructura i disseny
    2. HTML: estructura (header, section, footer)
    3. CSS/Tailwind: espais, colors, tipografia
    4. JS: interacció real

    🎓 Activitat típica per a alumnat

    Dissenya una landing page amb:

    • Header amb menú
    • Hero amb botó
    • 3 cards
    • Footer Després passa-la a HTML + Tailwind

    🎯 Conclusió clara

    • Figma no és dibuixar, és pensar com es construeix un web
    • Si saps HTML/CSS, Figma et fa millor desenvolupador
    • Auto Layout = Flexbox mental

    Si vols, en el pròxim missatge puc:

    • fer-te una pràctica guiada pas a pas
    • adaptar-ho a Tailwind
    • preparar un exercici d’avaluació

    Digues-me per a quin nivell (ESO, FP, DAW, autodidacta).
